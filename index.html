ГАЙД: SKETCHFAB → ИГРА
1
НАЙТИ МОДЕЛЬ

Sketchfab → фильтр Downloadable. Для персонажей: «low poly character», «gangster», «demon». Для оружия: «pistol low poly».

Бесплатные паки без атрибуции: Kenney, Quaternius. Персонажи с анимациями: Mixamo.

2
СКАЧАТЬ glTF

На Sketchfab жми Download 3D model → glTF. Нужен файл .glb (Binary) — он самодостаточный.

Если скачался .gltf + .bin + текстуры — перетащи все файлы сразу, загрузчик свяжет их сам.

3
КОНВЕРТАЦИЯ (FBX/OBJ)

Mixamo отдаёт FBX. Открой Blender: File → Import → FBX, затем File → Export → glTF 2.0, формат glTF Binary (.glb), +Y Up включён.

Быстрая проверка модели: gltf-viewer или Babylon Sandbox.

4
ОПТИМИЗИРОВАТЬ

Цель: < 3 МБ и < 15k треугольников на модель, текстуры ≤ 1024px. Иначе 20 врагов упрутся в FPS.

Сжатие: npx @gltf-transform/cli optimize in.glb out.glb или gltfpack -i in.glb -o out.glb -cc. Draco поддерживается загрузчиком.

5
ЗАГРУЗИТЬ ЗДЕСЬ

Выбери слот слева → перетащи файл. Авто-подгонка сама выставит рост и поставит ноги на пол. Правь масштаб/поворот/смещение справа — всё применяется мгновенно.

Модель сохраняется в браузере (IndexedDB) и переживает перезагрузку страницы.

6
ВЫЛОЖИТЬ НА GITHUB

Жми ЭКСПОРТ МАНИФЕСТА → получишь assets.json. В репозитории создай папку models/ (Add file → Create new file, имя models/.keep), загрузи туда свои .glb, а assets.json — в корень.

Игра сама подхватит манифест при запуске на Pages. Имена файлов в манифесте должны совпадать с загруженными.

Почему локальный файл работает, а URL — нет. Перетаскивание читает байты через FileReader и парсит их напрямую — сеть не участвует. Загрузка по URL с чужого домена (Sketchfab CDN) блокируется CORS; со своего GitHub Pages — работает.
